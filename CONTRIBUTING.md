# Contributing to bosh-gdc-cpi-release

Thank you for your interest in contributing to `cloudfoundry/bosh-gdc-cpi-release`!

## Contributor License Agreement (CLA) & Sign-Off

All contributors must have a signed Cloud Foundry Contributor License Agreement (**EasyCLA**) on file before Pull Requests can be merged. Please also sign off your commits (`git commit -s`).

## Submitting an Issue

We use the [GitHub issue tracker](https://github.com/cloudfoundry/bosh-gdc-cpi-release/issues) to track bugs and feature requests. Before submitting a bug report or feature request, please check that it has not already been filed.

## Submitting a Pull Request

1. Fork the repository and create a feature or bug-fix branch from `main`:
   ```bash
   git checkout -b <your-branch-name> main
   ```
2. Implement your feature or fix and include appropriate unit test coverage.
3. Ensure all formatting checks, static analysis, and tests pass locally.
4. Commit your changes with a sign-off trailer (`git commit -s`) and open a Pull Request targeting the `main` branch of [`cloudfoundry/bosh-gdc-cpi-release`](https://github.com/cloudfoundry/bosh-gdc-cpi-release).
